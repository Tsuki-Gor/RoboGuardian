# RoboGuardian

RoboGuardian verifies physical effects, maintains trusted memory, and supports recovery from execution faults in embodied agent harness frameworks. Accepted at **DAI 2026 (Oral)**.

This repository hosts the [project website](https://tsuki-gor.github.io/RoboGuardian/), [paper PDF](assets/papers/RoboGuardian.pdf), and demonstration videos.
